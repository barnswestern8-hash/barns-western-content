## Guia de uso para agentes

**Ao receber um produto no briefing:**
1. Identifique a categoria: Óculos / Fivelas / Bonés / Braceletes de cobre
2. Para Óculos e Fivelas: verifique o gênero indicado no briefing (Feminino / Masculino / Unissex)
3. Monte o path completo: `assets/products/{Categoria}/{Gênero}/{Nome} ({n}).ext`
4. Para múltiplas fotos do mesmo produto, selecione a numeração mais adequada ao contexto visual (ex: foto de perfil para cover de carrossel, foto frontal para slide técnico)

**Para conteúdo com influenciador:**
- Path: `assets/influencers/@{handle}/{arquivo}`
- Usar como referência de contexto/estilo, não como imagem de produto
