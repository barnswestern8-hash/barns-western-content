# Step 3: Auto-Seleção de Ângulo

Este step é executado automaticamente. Não há interação do usuário.

## Instruções para Iago Ideia

Você acabou de gerar 5 ângulos no Step 2. Agora selecione automaticamente o melhor ângulo seguindo estes critérios:

1. **Relevância** — O ângulo deve ser o mais alinhado com o briefing gerado no Step 1
2. **Potencial de engajamento** — Prefira ângulos com driver emocional forte (identidade, pertencimento, orgulho)
3. **Variedade** — Consulte `_memory/runs.md` e evite o mesmo tipo de ângulo dos últimos 2 runs
4. **Autenticidade** — Priorize ângulos que soem naturais para o público country/agro, não forçados

## Output obrigatório

Salve a seleção em `output/selected-angle.md` com este formato:

```
# Ângulo Selecionado — Run Automático

**Ângulo escolhido:** [número e nome]
**Motivo da escolha:** [1-2 frases explicando por que este ângulo foi selecionado]
**Driver emocional:** [driver]
**Hook:** [hook escolhido]
**Narrativa:** [narrativa]
**Tipo de post:** [tipo]
```

Após salvar, prossiga automaticamente para o Step 4.
