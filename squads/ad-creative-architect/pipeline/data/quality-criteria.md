# Quality Criteria: Ad Creative Architect

## Critérios por Agente

---

### Paula Psicóloga — Diagnóstico Psicológico

- [ ] Nível de consciência identificado (frio/morno/quente/muito quente/pronto) com justificativa
- [ ] Estado emocional atual descrito com linguagem específica da persona (não abstrata)
- [ ] Trava principal de compra identificada e nomeada com precisão
- [ ] Gatilho dominante escolhido (apenas UM — múltiplos gatilhos dilui o impacto)
- [ ] Tradução estratégica define ângulo, promessa e tipo de abordagem
- [ ] A saída seria reconhecida como correta por um profissional de marketing de performance

---

### Artur Ângulo — Hipóteses Criativas

- [ ] Mínimo 3 dores listadas em linguagem coloquial real do cliente (não marketeiro)
- [ ] Para cada dor: solução conectada ao produto Barns Western (não genérica)
- [ ] Mínimo 3 ângulos por dor, cada um com abordagem diferente (emocional, prova, racional)
- [ ] Mecanismo de conversão definido para cada hipótese (prova / garantia / benefício / diferenciação)
- [ ] Nenhum ângulo repete abordagem de outro ângulo na mesma dor
- [ ] A matriz poderia ser usada como briefing para um time de criação real

---

### Carlos Criativo — Geração de Criativos

**Por criativo gerado:**
- [ ] Gancho para o scroll em menos de 10 palavras (scroll-stop test: você pararia para ler?)
- [ ] Headline presente e diferente do gancho
- [ ] Copy adaptada à persona (vocabulário, tom, nível de consciência)
- [ ] Mecanismo de conversão presente (prova, garantia, benefício claro)
- [ ] CTA com intensidade correta para o nível de funil (soft para awareness, hard para conversão)
- [ ] Adaptação feita para Meta Ads E TikTok Ads com diferenças reais (não é a mesma copy com outro nome)
- [ ] Nenhum gancho é idêntico ou muito similar a outro na mesma sessão
- [ ] A copy soa como fala humana, não como press release
- [ ] Anti-commodity check: não poderia ser usada por qualquer concorrente sem mudança

---

### Diego Diretor — Protocolo Visual

**Por criativo:**
- [ ] Todos os 12 campos do protocolo visual preenchidos (nenhum pode estar ausente)
- [ ] Perfil do modelo é compatível com a persona descrita (gênero, idade, traço visual, estilo)
- [ ] Produto visível e com posição específica descrita (não vaga como "aparece na imagem")
- [ ] Iluminação e direção da luz especificadas com suficiente detalhe para briefar um fotógrafo
- [ ] Emoção transmitida é consistente com o gatilho dominante do criativo
- [ ] Visual e copy reforçam o mesmo gatilho emocional (não contraditórios)
- [ ] Protocolo de Meta Ads considera formato (feed vs. stories) na direção visual
- [ ] Protocolo de TikTok considera natureza nativa/UGC na direção visual

---

### Vera Veredito — Validação de Performance

**Processo:**
- [ ] Cada um dos 5 critérios pontuado de 1-10 com justificativa específica
- [ ] Nenhum score aparece sem "porque X" na mesma linha ou parágrafo
- [ ] Veredicto (APROVAR/REJEITAR) é claro e sem ambiguidade
- [ ] Cada criativo rejeitado tem lista de fixes específicos e acionáveis
- [ ] Fixes indicam O QUE mudar, ONDE e COMO (não "melhorar o gancho")
- [ ] Pontos fortes são reconhecidos mesmo em criativos rejeitados
- [ ] Score geral calculado corretamente (média dos 5 critérios)

## Benchmarks de Engajamento (Barns Western — baseline da investigação)

| Tipo | Curtidas | Comentários | Performance |
|------|---------|-------------|-------------|
| Carousel com hook sazonal + pergunta | 135 | 4 | Alta |
| Single image produto com copy telegráfica | 82 | 1 | Média |
| Single image lifestyle sem hook ativo | 44 | 0 | Baixa |

**Referência para calibrar qualidade:** Criativos aprovados pelo squad devem ter potencial para superar 135 curtidas orgânicas (baseline do melhor post analisado).

---

## Regras de Aprovação Global

| Condição | Decisão |
|----------|---------|
| Score geral ≥ 7.0 E nenhum critério < 4 | APROVAR |
| Score geral ≥ 7.0 E algum critério entre 4-6 | APROVAR CONDICIONALMENTE (fix necessário) |
| Score geral < 7.0 | REJEITAR |
| Qualquer critério < 4 | REJEITAR (gatilho duro, independente da média) |
| Protocolo visual com campo faltando | REJEITAR automaticamente |
