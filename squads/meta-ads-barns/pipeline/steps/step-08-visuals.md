# Step 08 — Briefings Visuais (Tiago Tela)

**Tipo**: Agent — inline
**Agente**: Tiago Tela 🎨
**Input**: copy-complete.md + buyer-personas.md + visual-specs.md
**Output**: squads/meta-ads-barns/output/visual-briefings.md

---

## Objetivo

Tiago cria briefings visuais production-ready para cada um dos 5 anúncios completos por persona selecionada — 3 variações de placement por anúncio (Feed 1:1, Feed 4:5, Reel/Story 9:16).

---

## Instruções para Tiago Tela

1. Ler `squads/meta-ads-barns/output/copy-complete.md` — os 5 anúncios por persona
2. Ler `squads/meta-ads-barns/output/buyer-personas.md` — driver emocional e perfil de cada persona
3. Ler `squads/meta-ads-barns/pipeline/data/visual-specs.md` — specs técnicas e paleta

4. Para cada anúncio completo por persona, criar briefing com 3 variações:

   **VARIAÇÃO A: FEED QUADRADO (1080x1080 / ideal 1440x1440)**
   - Tipo de imagem: [lifestyle / produto / editorial / UGC-style / comparativo]
   - Cenário: [localização específica com descrição de produção]
   - Talento: [gênero + faixa etária + estilo de apresentação]
   - Expressão e postura: [alinhada ao driver emocional da persona]
   - Produto: [como e onde aparece na composição]
   - Paleta: [tons primários + acento — nomes específicos]
   - Estilo visual: [fotografia realista / editorial / cinematográfico / UGC-style]
   - Texto overlay: [máx 5 palavras + posição]
   - Prova social visual: [badge / screenshot / rating — se aplicável]

   **VARIAÇÃO B: FEED VERTICAL (1080x1350 / ideal 1440x1800)**
   - Ajuste de composição para formato 4:5
   - Mais espaço vertical: produto + cenário com mais contexto

   **VARIAÇÃO C: REEL / STORY (1080x1920 / ideal 1440x2560)**
   - Safe zone TOPO: 250px — região proibida para texto/produto crítico
   - Safe zone BASE: 340px — região proibida para texto/produto crítico
   - Frame 0-2s: hook visual [o que aparece nos primeiros 2 segundos]
   - Frame 2-10s: desenvolvimento [descrição dos frames seguintes]
   - CTA frame: [posição + texto — dentro da safe zone]
   - Texto overlay por frame: máx 5 palavras, posicionado na zona central

5. Salvar em `squads/meta-ads-barns/output/visual-briefings.md`

---

- [ ] Paleta com tons específicos nomeados
- [ ] Expressão do talento alinhada ao driver da persona
- [ ] Overlay de texto máx 5 palavras
